# Sistema B1 · Válvula maestra (7) y espárragos (8)

Esta es una extracción de las páginas del proyecto original suministrado por el usuario. Conserva sus estilos, dibujos y lógica de simulación. El menú de las páginas se restringió a los componentes 7 y 8.

## Cómo verla

- Abre `index.html` para seleccionar componente.
- Página 7: `componentes/vmaestra.html`.
- Página 8: `componentes/esparragos.html`.
- Todas las carpetas CSS y JS deben quedarse en su lugar.

## Cómo publicar y obtener un enlace público

1. Crea un repositorio público en GitHub, por ejemplo `simulador-b1-valvula`.
2. Sube **el contenido de esta carpeta** a la raíz del repositorio (no subas el ZIP sin extraer).
3. Abre Settings → Pages y selecciona Deploy from a branch → `main` → `/(root)` → Save.
4. GitHub mostrará la URL pública al terminar la publicación, típicamente `https://USUARIO.github.io/simulador-b1-valvula/`.
5. Para compartir directamente la página 7 añade `componentes/vmaestra.html`; para la 8 añade `componentes/esparragos.html`.
